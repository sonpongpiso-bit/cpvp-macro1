# CPvP Macro (Fabric 26.1.2)
Needs JDK 25, Gradle 9.x, Fabric Loader 0.19.1+, Fabric API 0.145.4+26.1.2.
Build: `gradle wrapper` then `./gradlew build` (Windows: `gradlew build --no-daemon`).
Jar: build/libs/cpvpmacro-1.0.0.jar -> .minecraft/mods
R toggles. Hold end crystals; aim at obsidian/bedrock to place, aim at a crystal to break.
Tune DELAY_TICKS in CpvpMacroClient.java.
